# NovaMind Agency — Web

Sitio web desarrollado para una agencia ficticia de marketing digital y diseño, creado **desde cero como parte de mi portafolio de desarrollo web**.

## 📌 Sobre el proyecto

NovaMind Agency es una página web enfocada en representar la presencia digital de una agencia moderna. El proyecto fue desarrollado con el objetivo de practicar y demostrar mis habilidades en **diseño web, estructura HTML y desarrollo frontend**.

El diseño busca transmitir una imagen moderna, profesional y orientada al sector digital.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3

## ✨ Características

* Diseño moderno y profesional
* Estructura web organizada
* Diseño adaptable a diferentes tamaños de pantalla
* Secciones orientadas a una agencia digital
* Interfaz enfocada en una experiencia visual limpia
* Desarrollo realizado desde cero
